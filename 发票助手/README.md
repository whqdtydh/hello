# 发票助手（InvoiceAssistant）

桌面软件：左侧内嵌 QQ 邮箱网页勾选发票/行程单邮件，右侧填写 IMAP 账号后，程序用 IMAP 直连匹配勾选邮件并自动下载 PDF 附件，按规则命名归档。

## 功能

- 内嵌 QQ 邮箱网页（QtWebEngine），复用浏览器会话，**首次扫码，之后免登录**。
- IMAP 直连下载，远快于网页嗅探；勾选哪些就下载哪些。
- 自动识别发票类型（行程单 / 高铁 / 高速 / 打车 / 酒店 / 餐饮 / 停车 / 加油 / 机票 / 快递 / 通讯 / 水电等）。
- 高铁邮件自动从正文表格提取乘车日期、发到站、票价用于命名。
- 支付宝电子发票通知（无附件）自动提取正文 PDF 直链直接下载。
- 下载完成后按合计金额归档到「xx.xx元」子文件夹。
- 实时日志 + 进度条，支持停止；IMAP 凭据本地保存，二次免输入。

## 运行环境

- Windows + Python 3.10+（已在 3.12 验证）
- QQ 邮箱需在网页版「设置 → 账户 → 开启 IMAP/SMTP 服务」生成授权码

## 安装与运行

```bat
pip install -r requirements.txt
python main.py
```

## 使用步骤

1. 启动后左侧自动打开 QQ 邮箱，扫码登录（会话已保存，二次免登录）。
2. 在左侧勾选要下载的发票/行程单邮件（可进入「报销」文件夹）。
3. 右侧填写 IMAP 账号（`QQ号@qq.com`）与授权码，确认保存目录（默认 `桌面\车辆报销`）。
4. 点「开始下载」，等待完成；核对文件名与数量。

## 项目结构

```
发票助手/
├── main.py                     # 入口
├── requirements.txt
├── app/
│   ├── config.py               # 路径 + CSS 选择器（邮箱改版请优先改这里）
│   └── engine/
│   │   ├── mail_parse.py       # 邮件解析纯函数（MIME / 正文 / 附件 / 发票类型）
│   │   ├── imap_engine.py      # IMAP 搜索 + 附件下载引擎
│   │   ├── downloader.py       # 内嵌浏览器嗅探下载控制器（备用方案）
│   │   ├── web_client.py       # QtWebEngine 页面自动化
│   │   ├── cookie_store.py     # cookie 收集与持久化（供 requests 复用会话）
│   │   └── imap_utf7.py        # IMAP modified UTF-7 编解码
│   └── ui/main_window.py       # 主窗口
└── scripts/                    # 开发期诊断脚本
```

## 常见问题

- **授权码失效**：重新点「打开邮箱」登录，再在右侧重填授权码即可。
- **界面改版导致失效**：打开 `app/config.py`，按当前网页元素调整选择器。
- **未匹配到邮件**：确认已在左侧勾选邮件、账号已开启 IMAP 且授权码正确。

## 备注

- 本软件仅用于读取本人邮箱并下载发票附件，请在授权范围内使用。
- 会话与凭据保存在 `C:\Users\<用户名>\.invoice_assistant`。
