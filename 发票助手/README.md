# 发票助手（InvoiceAssistant）

桌面软件：左侧内嵌 QQ 邮箱网页，在网页里勾选发票/行程单邮件，程序用 QQ 邮箱接口直连下载 PDF 附件，按规则命名并按合计金额归档。

## 功能

- 内嵌 QQ 邮箱网页（QtWebEngine），扫码登录，**会话持久化，二次免登录**。
- **边勾边读**：勾选邮件的瞬间后台即开始预读该邮件详情，勾完点下载时零等待直接下载。
- **并发下载**：多封邮件 3 线程并发，单封附件 6 线程并行，边拉列表边处理。
- 自动识别发票类型（行程单 / 高铁 / 高速 / 打车 / 酒店 / 餐饮 / 停车 / 加油 / 机票 / 快递 / 通讯 / 水电等）。
- 命名日期**行程单票面优先**（= 消费当天）> PDF 票面日期（高速发票取票面通行时间）> 邮件日期；兜底场景生成 `待确认日期.txt` 提示核对。
- 金额从 **PDF 票面提取**（价税合计等固定字段），下载后按合计金额归档到 `xx.xx元` 子文件夹。
- 下载结果树：顶部总结（应下载邮件数 / PDF 数 / 总金额 / 行程单数 / 失败数 / 类型分布 / 待确认日期），每封邮件一个分组展示成功或失败详情，**支持 Ctrl+C 复制**。
- **接口失效自动学习**：腾讯改版导致接口路径变化时，手动在网页操作一次，程序自动记录请求并匹配更新。
- 一键**更换 QQ 邮箱**（清空 cookie 重新扫码）。

## 运行环境

- Windows + Python 3.10+（已在 3.12 验证）
- 无需额外开启 IMAP，只需 QQ 邮箱网页版正常登录

## 安装与运行

```bat
pip install -r requirements.txt
python main.py
```

开发/排障模式（带崩溃日志、禁用 GPU 防闪退）用 `python start.py`，日志输出到 `crash_diag.log` 与 `%TEMP%\invoice_crash.log`。

## 使用步骤

1. 启动后左侧自动打开 QQ 邮箱，扫码登录（会话已保存，二次免登录）。
2. 在左侧网页勾选要下载的发票/行程单邮件（勾选瞬间后台开始预读）。
3. 确认右侧保存目录（默认 `桌面\车辆报销`）。
4. 点「开始下载」，等待完成；结果树顶部查看总结，展开邮件分组核对成功/失败详情。
5. 勾选状态默认保留，可反复核对、再次下载。

## 常见问题

- **接口失效**：程序会提示，按提示在左侧网页手动操作一次（打开收件箱 / 打开邮件 / 下载发票），再点「开始下载」，将自动学习新接口。
- **闪退 / 卡顿**：用 `python start.py` 启动，把 `crash_diag.log` 最后内容发来排查。
- **勾选没识别**：勾选后稍等 1~2 秒再下载；确认勾选框出现明确勾选标记。
- **日期不对**：查看保存目录下 `待确认日期.txt`，兜底日期（来自邮件日期）的文件名在其中列出，手动改名即可。

## 备注

- 本软件仅用于读取本人邮箱并下载发票附件，请在授权范围内使用。
- 会话与缓存保存在 `C:\Users\<用户名>\.invoice_assistant`。
